# Gaumard Automated Scenario & Palette Configuration Guide 

## Overview
This Standard Operating Procedure (SOP) documents the step-by-step configuration required to automate Pediatric Advanced Life Support (PALS) scenarios within the Gaumard simulator control software. 

By pre-configuring custom palettes, vitals triggers, and timed scenario transitions, this workflow removes manual software toggling during live simulations, ensuring consistent scenario delivery, higher fidelity, and seamless execution for clinical instructors[cite: 1].

---

## Objective
* **Automation:** Program automated physiological responses and vitals transitions on a timed schedule (e.g., 2-minute delay triggers)[cite: 1].
* **Standardization:** Ensure pediatric resuscitation scenarios (e.g., "PALS 2B") execute identically across multiple training sessions[cite: 1].
* **Operational Efficiency:** Provide quick-reference documentation for simulation technicians and clinical faculty to minimize pre-scenario setup time[cite: 1].

---

## Step-by-Step Configuration Workflow

### Phase 1: Palette Creation
1. Open the **Palette** tab within the software interface[cite: 1].
2. Select **New Default** to establish baseline patient vitals[cite: 1].
3. Under **Vitals**, select **Enter Vitals** to input required physiological parameters[cite: 1].
4. Click **Create**[cite: 1].
5. Assign the Title: `PALS 2B`[cite: 1].
6. Click **Save**[cite: 1].

### Phase 2: Scenario Assembly & Automation
1. Navigate to the **Scenario** tab[cite: 1].
2. In the scenario search bar, search for the newly created palette: `PALS 2B`[cite: 1].
3. Select **+ Item** to add the palette to the scenario timeline[cite: 1].
4. Set the transition timer (e.g., `2 mins`)[cite: 1].
5. Select **Add** to confirm the timed event[cite: 1].
6. Click the gray **SAVE** button (located above the green execution button) to store the scenario logic[cite: 1].

### Phase 3: Finalizing Scenario Documentation
1. Input the official **Scenario Name** (`PALS 2B`)[cite: 1].
2. Copy and populate the **Scenario Description / Synopsis** directly from the standardized PALS course booklet to ensure clinical alignment[cite: 1].
3. Save the completed scenario file to the master library[cite: 1].
